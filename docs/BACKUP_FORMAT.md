# Формат полного архива v1

Файл UTF-8 JSON. Оболочка:

```json
{
  "format": "time-counter-backup",
  "version": 1,
  "createdAt": "ISO-8601 timestamp",
  "checksum": "SHA-256 in lowercase hexadecimal",
  "payload": {}
}
```

`payload` — полное состояние: `schemaVersion`, `revision`, `updatedAt`, `days`, `studies`, `months`, `years`, `settings`, `timer`, `meta`. Даты дней — `YYYY-MM-DD`, месяцев — `YYYY-MM`. Длительности — целые минуты; секундомер хранит секунды и Unix timestamp в миллисекундах. Связи изучений — стабильные ID. `months.source` различает `daily` и `manual`; месячный итог не складывается повторно с дневными записями. История назначения и целей находится в соответствующих периодах.

Контрольная сумма рассчитывается от канонической JSON-сериализации `payload`: ключи объектов сортируются, порядок массивов сохраняется, пробелы отсутствуют. Контрольная сумма обнаруживает повреждение, но не является шифрованием или защитой от преднамеренного изменения файла.

Перед записью импорт проверяет формат, версию, размер до 20 МБ, контрольную сумму, все сущности и связи. Поддерживается версия 1. Неизвестная версия отклоняется без замены базы. Для будущей версии потребуется явная миграция; обещания поддержки ещё не существующих форматов нет.

Восстановление полностью заменяет текущий документ одной транзакцией и сохраняет предыдущий документ в ключе `recovery` локальной базы. Автоматического объединения нет. Предыдущая восстановительная копия заменяется при следующем восстановлении. Полный архив содержит актуальные пользовательские данные, но не служебную копию `recovery`.

Файл содержит личную историю открытым текстом. Передавайте его только туда, где хотите хранить свою резервную копию. В репозиторий проекта он не входит.
