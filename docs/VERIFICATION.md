# Проверки первой версии

1 ноября 2026 года, Mac / Chrome. Все данные проверок вымышленные.

- `npm test`: 11 успешных проверок времени, календаря, месячного и годового учёта, изучений, закрытия месяца, секундомера и полного архива.
- `npm run build`: успешная статическая сборка без установки зависимостей. Опубликованный кэш получает идентификатор по содержимому файлов.
- Отдельный браузерный стенд использует настоящие `storage.mjs`, `core.mjs`, `backup.mjs` и IndexedDB в другом origin: 13 успешных проверок. Подтверждены отсутствие потерянных одновременных записей, атомарный откат, перенос всех разделов 11 лет / 132 дней, восстановительная копия, повторный импорт без дублей и отказ от повреждённого архива.
- Основной интерфейс: прямой ввод 2:30, сохранение после перезагрузки, создание изучения и связь с днём, итог месяца, подготовка JSON-файла. Проверено отображение на узком экране 402 × 874 и в окне компьютера.
- Офлайн: локальный сервер остановлен, HTTP-подключение не проходит; перезагрузка уже установленного веб-приложения открывает интерфейс и сохранённые 2:30 / изучение.
- В исходниках нет сетевой отправки записей. Единственные `fetch` находятся в service worker и обслуживают файлы программы. На новом опубликованном адресе открывается отдельная пустая база.
- Публикация: GitHub Actions успешно проверил, собрал и разместил приложение по HTTPS. Первый workflow: https://github.com/ErikEgl/time-counter/actions/runs/41338719194.

## Что ещё проверить на телефоне

- Установка из Safari через «На экран Домой» и повторный запуск без сети.
- Секундомер при блокировке экрана, выгрузке приложения, паузе и повторном открытии.
- Системное сохранение JSON в «Файлы» и выбор этого файла для восстановления на другом устройстве.
- Крупный текст, клавиатура и безопасные области именно iPhone 17 Pro.

Автоматизация системного выбора/скачивания файла на Mac ограничена разрешениями расширения Chrome. Это не считается пройденной проверкой системного меню iPhone. Логика JSON, сохранения и восстановления самой базы проверена отдельно. Нет обещания бессрочного хранения без внешнего архива: удаление приложения или очистка веб-данных может удалить локальную базу.
