# План создания «Мой отчёт»

Дата: 1 ноября 2026 года. Разработка и публикация на GitHub разрешены владельцем.

## Результат

Личное приложение PWA для iPhone 17 Pro. Установка из Safari на домашний экран, отдельное окно, офлайн-работа, локальная база IndexedDB. Бесплатный публичный GitHub Pages выдаёт только файлы программы. Личные записи, имена, отчёты и архивы не отправляются на сервер. Приложение начинает с пустой базы.

В репозиторий входят программа, этот план, описание формата архива, инструкция и тесты с вымышленными данными. Исходные фотографии и частные исследовательские заметки владельца остаются на его компьютере.

## 1. Каркас и оформление

- Статические HTML/CSS/JavaScript-модули без внешних библиотек, шрифтов, аналитики и CDN.
- Пять разделов: «День», «Месяц», «Архив», «Изучения», «Настройки».
- Привычное оформление: тёмный фон, оранжевые значения, синие действия, крупные кнопки. Дополнительные светлая и ночная темы.
- Интерфейс для узкого экрана, безопасных областей iPhone и увеличенного текста; на планшете и компьютере используются дополнительные столбцы.
- Собственные векторные значки и PNG-иконки 180/192/512 пикселей. Чужие изображения не копируются.

Готово, когда навигация, формы, календарь и кнопки помещаются на телефонном экране и работают с клавиатуры.

## 2. База и правила

- IndexedDB хранит один версионированный документ: дни, изучения и их связи с днями, месяцы, годовые цели, настройки, секундомер и метаданные.
- Каждое изменение выполняется атомарной транзакцией чтение–изменение–запись. Сообщение о сохранении появляется после завершения транзакции. Ошибка записи показывается пользователю.
- Дата хранится календарной строкой `YYYY-MM-DD`; длительность — целыми минутами, секундомер — целыми секундами и отметками времени.
- Настройки цели и назначения копируются в период при его первом создании. Изменение общих настроек не переписывает прошлые месяцы.
- Редактирование из другой вкладки синхронизируется через BroadcastChannel; транзакции не должны затирать независимые изменения.
- При восстановлении полного архива предыдущая база сохраняется локальной восстановительной копией.
- Запрос постоянного хранения через Storage API выполняется по доступности. Отказ не маскируется, работа остаётся возможной, внешние архивы нужны независимо от результата.

Готово, когда запись переживает перезапуск, ошибки не показываются как успех, а импорт не может частично заменить базу.

## 3. День и календарь

- Счётчики публикаций, видео и повторных посещений, время, изучения, другие часы и заметка.
- Крупные `−/+`; шаг времени выбирается из 1, 2, 5, 10, 15, 20, 30 минут. Прямой ввод числа или времени `часы:минуты`.
- Числа не бывают отрицательными. Время `1:30` означает 90 минут.
- Автосохранение включено по умолчанию. При выключении показывается явная кнопка сохранения черновика.
- Выбор даты, переход на сегодня, сетка месяца с записанным временем и выделенными выходными, начало недели в понедельник или воскресенье.

## 4. Месяц, архив и цели

- Список дней и итоги месяца, прогресс цели, среднее за активный день, остаток до цели и необходимый темп до конца периода.
- Архив служебных лет сентябрь–август; месяцы учитываются один раз.
- Исторический месяц можно внести общим итогом без дневной детализации. Для одного месяца нельзя одновременно учитывать ручной итог и сумму дней.
- Закрытие доступно для завершённого месяца, фиксирует итог и сохраняет все дни. Для редактирования нужен явный возврат месяца к открытому состоянию.
- Дополнительный защищённый режим ограничивает изменения прошлых периодов.
- Исторические назначения и цели сохраняются отдельно. Значения целей можно менять: это личные настройки, а не зашитые нормативы.

## 5. Изучения и секундомер

- Добавление, изменение и архивирование человека. Архивирование сохраняет участие в прошлых днях.
- Дневной показатель — выбранные люди плюс безымянный счётчик. Месячный — уникальные люди за месяц плюс максимум безымянного счётчика за один день. Это явное правило первой версии; оно не объявляется точным восстановлением неизвестной логики оригинала.
- Секундомер: начало, пауза, продолжение, остановка и добавление результата в день. Время восстанавливается по сохранённой отметке после блокировки и перезапуска.
- Автоостановка ограничивает интервал выбранным числом часов. Время относится к дате начала. Добавление выполняется однократно.
- Другие часы хранятся отдельно и показываются отдельно; первая версия считает цель по основному времени.

## 6. Полный архив и многолетние данные

- Кнопки «Сохранить все данные» и «Восстановить данные».
- JSON-архив содержит весь документ базы, версию формата, дату и SHA-256 содержимого.
- Проверяются размер, структура, даты, диапазоны чисел, уникальность ключей, ссылки на изучения и контрольная сумма. Неизвестная версия или повреждённый файл не меняют базу.
- До восстановления показывается объём архива и подтверждение полной замены. Текущая база сохраняется восстановительной копией.
- Повторное восстановление того же архива не создаёт дубликатов. Поддерживаемые старые версии проходят миграции.
- Подготовка файла не выдаётся за подтверждение его сохранения в iCloud: пользователь выбирает место в системном меню. Интерфейс показывает дату подготовки последнего архива и напоминание, если копия давно не готовилась.
- Формат описан в отдельном документе и пригоден для будущего переноса на другой адрес или другую реализацию приложения.

## 7. Настройки и отчёт

- Тема, левша, объёмные кнопки, разделители, порядок списка, шаг времени, крупный секундомер, автосохранение, защищённый режим.
- Показ/скрытие старых счётчиков без удаления данных; месячная и годовая статистика, цели и назначение.
- Русский интерфейс первой версии; строки собраны так, чтобы добавить переводы позже. 27 непроверенных переводов не имитируются.
- Отчёт за месяц: просмотр, копирование, системная отправка. Режим без минут отбрасывает минуты только в тексте отчёта; база сохраняет точное время. Это документированное правило первой версии.
- Справка об установке, локальной базе, резервной копии, секундомере и приватности встроена в приложение.

## 8. Офлайн-работа и обновления

- Manifest с относительными адресами работает и в подпапке GitHub Pages.
- Service worker сохраняет файлы приложения для офлайн-запуска. Кэш программы отделён от пользовательской базы.
- Обновление предлагается кнопкой. Старая база сохраняется; обновление не требует переустановки и не очищает записи.
- Публикуется только каталог сборки, без тестовых архивов, исходных фотографий, секретов и частных заметок.

## 9. Проверки

1. Автоматические проверки арифметики времени, дат/служебных лет, месячного и годового учёта, ручных месяцев, изучений и секундомера.
2. Проверки полного экспорта/импорта, повреждённого файла, неподдерживаемой версии и повторного восстановления.
3. В браузере: ввод, сохранение, перезагрузка, календарь, архив, изучения, секундомер, настройки и отчёт.
4. Отдельный перенос нескольких лет вымышленных данных в чистую базу с полным сравнением сущностей и связей.
5. Офлайн-запуск и отсутствие отправки введённых данных по сети. Визуальная проверка узкого и широкого экранов.
6. Проверка сборки и HTTPS-адреса GitHub Pages. Проверка именно домашнего экрана физического iPhone выполняется при доступе к телефону; симуляция ширины не подменяет её.
