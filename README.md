# Мой отчёт

**[Открыть приложение](https://erikegl.github.io/time-counter/)** · [План разработки](docs/BUILD_PLAN.md)

Личный дневник служения для iPhone. Устанавливается на домашний экран как PWA, хранит записи на устройстве и работает офлайн после загрузки файлов.

## Возможности

- День: время, публикации, видео, повторные посещения, изучения, другие часы и заметки.
- Календарь с временем по дням; месяцы и архив служебных лет.
- Личные цели, прогресс, назначения по периодам, исторические месяцы общим итогом.
- Изучения с архивированием; секундомер с паузой, автоостановкой и восстановлением.
- Полный JSON-архив всех записей, связей и настроек для переноса на другой телефон.
- Тёмная, светлая и ночная темы; крупные кнопки, левша, настройки ввода и отчёта.

## Установка на iPhone

1. Откройте [приложение](https://erikegl.github.io/time-counter/) в Safari.
2. «Поделиться» → «На экран Домой», включите открытие как веб-приложения.
3. Запустите через иконку. В настройках дождитесь «Работа без интернета: Файлы готовы».
4. Периодически сохраняйте полный архив в «Файлы» / iCloud Drive или на компьютер.

У PWA нет профиля подписи Xcode и семидневного срока его действия. Работа именно на физическом iPhone должна быть проверена владельцем после установки; браузерная проверка на Mac не заменяет её.

## Где данные

База IndexedDB находится в хранилище приложения на вашем устройстве. Программа не отправляет записи на сервер: нет аккаунтов, общей базы, аналитики, внешних библиотек и шрифтов. Публичный сайт содержит только программу. Другой посетитель начинает со своей пустой базы. Хостинг может вести стандартные журналы загрузки файлов; содержимое дневника в запросах отсутствует.

История не синхронизируется автоматически. Веб-хранилище может быть очищено системой или пользователем, поэтому необходим внешний архив. Подготовка архива не подтверждает его сохранение в iCloud: завершите сохранение в системном меню. В архив входят личные данные; храните этот файл у себя, не добавляйте его в репозиторий.

## Перенос на новый телефон

На старом устройстве: «Настройки» → «Сохранить всё» → сохраните JSON-файл вне приложения. На новом: установите приложение → «Восстановить» → выберите файл → подтвердите замену. Текущая база перед заменой сохраняется локальной восстановительной копией. Повторный импорт заменяет базу, сохраняя идентификаторы; объединения двух независимых историй нет.

## Запуск и проверки

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
npm test
npm run build
npm run dev
```

Локальный адрес: `http://127.0.0.1:4173/time-counter/`. Папка `dist/` содержит готовую статическую сборку. GitHub Pages уже настроен на источник GitHub Actions. Workflow запускает тесты, собирает файлы и публикует их по HTTPS.

## Правила первой версии

- Время хранится целыми минутами; секундомер добавляет только полные минуты к дате начала.
- Месячные изучения — уникальные отмеченные люди плюс максимум безымянного счётчика за один день.
- Другие часы сохраняются отдельно от основного времени и его цели.
- «Без минут» меняет текст отчёта, отбрасывая минуты, и сохраняет точную исходную запись.
- Служебный год — сентябрь–август. Закрытие месяца сохраняет всю дневную историю.
- Русский язык; дополнительные переводы не включены.
